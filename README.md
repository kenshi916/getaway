# HEIST — Midnight Withdrawal

A self-contained, static Three.js browser game. Serve `dist/` over HTTP. No build or package installation is required. All runtime libraries, fonts, and models are included locally.

Play a five-minute solo bank heist against animated security bots. Crack the vault, collect three cash stacks, use smoke and cover, and escape at the van. Keyboard, mouse, and touch controls are supported. Loot is practice score; multiplayer, wallets, token markets, and payouts are not connected.

Models: Kenney Blocky Characters, Car Kit, City Kit Roads, Furniture Kit (CC0). Character GLBs include the original animations and embedded textures. Asset acknowledgments appear in the game.

Rendering: Three.js 0.170.0 (MIT). Typography: Space Mono (SIL Open Font License). See `dist/assets/LICENSES.txt`.
